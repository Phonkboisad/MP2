## Features
- **Responsive Navigation Bar:** Sticky top header with smooth section scrolling and a collapsible hamburger menu on mobile screens.
- **Structured Content Sections:** Includes Hero, About, Filterable Projects, Technical Skills, and Contact sections using semantic HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **Dynamic DOM Rendering:** Project cards and technical skill groups are stored as JavaScript arrays of objects and dynamically rendered into the DOM.
- **Interactive UI Components:**
  - Category filter buttons (`All`, `Hardware & Robotics`, `Web & Automation`, `Cybersecurity`)
  - Interactive project details preview modal
  - Client-side contact form validation with instant user feedback

## Tech Stack
- **HTML5** (Semantic structure)
- **Tailwind CSS v4** (`@tailwindcss/browser@4` CDN)
- **Vanilla JavaScript (ES6+)**

## How to Run
1. Clone or download this repository.
2. Open `index.html` directly in any modern web browser (Chrome, Edge, Firefox, Safari). No build tools or local server required.
